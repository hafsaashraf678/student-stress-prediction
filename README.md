# 🎓 Student Stress Prediction Dashboard

ML dashboard to predict university student stress levels using Python & Streamlit.

## 📊 Models Used
- Linear Regression — R²=0.85, Accuracy 81.33% ✅ Best
- SVR (RBF) — R²=0.80, Accuracy 79.50%
- Random Forest — R²=0.76, Accuracy 79.83%

## 📁 Dataset
3,000 university students · 18 features

## 🚀 How to Run
streamlit run app.py
